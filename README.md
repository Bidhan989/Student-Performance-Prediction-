# StudentAI — Student Performance Prediction System

A full-stack Django + Machine Learning project for estimating mathematics performance and classifying student pass/fail outcomes.

- Django 6
- SQLite

- pandas / NumPy
- scikit-learn
- XGBoost

## Machine Learning Pipeline

`train_models.py` is the training source used by Django.

1. Loads `StudentsPerformance.csv`.
2. Creates `average_score` from mathematics, reading and writing.
3. Creates the pass/fail target using an average threshold of 60.
4. Label-encodes five categorical features.
5. Uses reading score, writing score and encoded student information as model inputs.
6. Splits the data into 80% training and 20% held-out testing data with `random_state=42`.
7. Trains:
   - Ridge Regression
   - XGBoost Regression
   - SVM Classifier
   - XGBoost Classifier
8. Evaluates the models on the held-out test set.
9. Saves the trained models and preprocessing objects to `ml_models/model_bundle.joblib`.
10. Saves evaluation metrics to `ml_models/model_metrics.json`.

- predicted mathematics score
- estimated average
- performance category
- final decision
- Ridge output
- XGBoost regression output
- SVM decision
- XGBoost classification decision

## Run on Windows

```powershell
cd Student_performance
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

python train_models.py

python manage.py makemigrations
python manage.py migrate

python manage.py createsuperuser
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```

Admin:

```text
http://127.0.0.1:8000/admin/
```

Custom staff dashboard:

```text

```
