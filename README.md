# Student Performance Prediction Using Machine Learning

This project predicts student academic performance and pass/fail outcomes using machine learning techniques. It includes data preprocessing, feature engineering, model training, and performance evaluation using multiple classification algorithms.

## Features
- Data preprocessing and cleaning
- Feature engineering
- Model training and evaluation
- Comparison of multiple machine learning models
- Performance analysis using evaluation metrics

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn

## Project Goal
The objective of this project is to analyze student academic and demographic data to build predictive models that estimate student performance and classify pass/fail outcomes, helping identify students who may require additional academic support.
